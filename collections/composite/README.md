## 用户参数

在工具包卡片点击「参数」，居中弹窗按任务和目标分组。任务备注、额外间隔和旧版支持步骤收进高级/兼容设置，升级仍保留其值；酷狗只有默认通用参数时隐藏参数按钮，日常直接启停工具包。

- 起点提供五类业务；滚页和领奖跟随业务接续，保留旧版手动关闭值。
- QQ金币提供礼物、定时、宝箱、视频四类及追加广告选择；QQ免费听歌提供本轮访问数量，不伪装为听歌收益分钟数。关闭选择后完成已开始的停留、返回和领奖；原生停用/撤权仍立即生效。
- 安装类明确区分本轮安装数量、钱包金币总额和网盘“已打开”累计数量。可选保留或清理本轮新装应用，只接受唯一新装凭据。主题三区独立选择，数量及清理随任务区开关显示。
- 淘宝可选择直接领取/搜索/浏览；“衣服、鞋子、数码”是随包签名的固定预设，不开放任意文本或扩大输入权限。
- 可选本轮数量填0时沿用原包流程；正整数才启用用户减量目标。汽水保留原包默认300上限，减量时显示目标，已关闭广告与收益确认分别描述。没有新增默认截止时间。
- 星空按常规/种菜/偷菜模式显示相关参数，显示项明确只控制前台助手内容，后台提示样式保持。金铲铲可在下次进游戏沿用最近阵容，旧阵容移除则提示重选；配色和分页收进高级设置，仍不代替玩家操作。助手类参数按界面提示重开后生效。

微信等信息流规则的原图、语音和应用子选项统一点击“保存”后生效；关闭丢弃草稿，未改的默认值继续跟随包更新。开屏继续使用原有应用管理入口。本轮没有把不可靠的原图选中状态当成已修复，也没有新增自动发送或付费云服务权限。

用户覆盖值与签名正文分开持久化，更新不覆盖自定义值。新增参数采用包默认值；已删除参数的旧值保留但不传给脚本。旧值不符合新的类型／范围时保留原值，等待用户修正或恢复默认，不静默丢弃。停用状态在更新后保留。

## 仓库结构与维护

- `index.json`：schema 2多版本索引，记录版本、相对地址、完整文件SHA-256和兼容要求。
- `packs/<id>/<version>.json`：不可覆盖的签名正文；新内容递增版本，保留既有正文。
- 清单要求与真实签名manifest一致，合集不会扩大包权限或替代用户的发布者确认；新增能力仍须用户确认。
- 每个合集最多32个工具、每工具32个版本、总共128个版本；超过时另建合集。
- 顶层 `index.json`、旧包路径与旧订阅入口保持，本轮只追加本目录的复合工具版本。
