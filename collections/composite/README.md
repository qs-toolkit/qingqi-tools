## 用户参数

在工具包卡片点击「参数」，居中弹窗显示该签名包实际提供的选项。不同工具可提供任务区／子任务开关、广告或安装任务数量、进度备注、额外动作间隔等参数；具体选项和默认值以对应包为准。默认配置沿用原业务流程，参数不能放宽宿主输入和授权保护。

星空的常规、种菜、偷菜模式及对应选项由包提供；金铲铲支持深色助手页面与阵容库每页4–12条，保留全部阵容。助手类参数按界面提示重启相应助手会话后生效。金铲铲提供参考与标注，不代替玩家操作游戏；现有云端付费请求限制保持。

用户覆盖值与签名正文分开持久化，更新不覆盖自定义值。新增参数采用包默认值；已删除参数的旧值保留但不传给脚本。旧值不符合新的类型／范围时保留原值，等待用户修正或恢复默认，不静默丢弃。停用状态在更新后保留。

最新版本各含 **2个JS脚本、3份业务配置**（rules、policy、config）及许可文本。manifest、摘要清单和签名属于验签元数据，不计业务配置；内联共享库不虚报为独立文件，实际成分以轻启卡片和文件明细为准。

## 仓库结构与维护

- `index.json`：schema 2多版本索引，记录版本、相对地址、完整文件SHA-256和兼容要求。
- `packs/<id>/<version>.json`：不可覆盖的签名正文；新内容递增版本，保留既有正文。
- 清单要求与真实签名manifest一致，合集不会扩大包权限或替代用户的发布者确认；新增能力仍须用户确认。
- 每个合集最多32个工具、每工具32个版本、总共128个版本；超过时另建合集。
- 顶层 `index.json`、旧包路径与旧订阅入口保持，本轮只追加本目录的复合工具版本。
