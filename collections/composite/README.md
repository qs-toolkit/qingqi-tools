# 轻启复合工具包合集

在轻启 **1.2.9（129121）或更新版本**的「工具包 → 导入 → 订阅链接」粘贴：

```
https://raw.githubusercontent.com/qs-toolkit/qingqi-tools/main/collections/composite/index.json
```

国内网络可在原始地址前添加自己信任的镜像前缀。合集内地址均为相对路径，随合集地址解析。

轻启先根据当前本体版本、系统 API、Host API 和支持功能筛选各包的版本，再验签实际正文；每个工具只显示一个最高可用版本，没有兼容版本的工具不会出现在勾选列表。清单声明与签名正文不符、摘要不符或签名损坏的版本不作为可用版本。检查更新继续沿同一合集链接选择版本，保留启停状态，不自动降级。旧轻启尚未实现这套合集解析，需要先升级到 129121。

## 用户参数

任务包支持「进度备注」和「额外动作间隔（0–1000 毫秒）」，默认空备注、0 间隔，沿用原任务流程。配置不改变目标声明、页面归属、停止或输入保护。任务下次执行生效。

金铲铲助手支持「深色助手页面」和「阵容库每页条数（4–12）」，需完全退出轻启再重新打开后生效；全部阵容仍可翻页查看。金铲铲只给参考与标注，不代替玩家操作游戏。现有云端价格校验已到期，因此云端付费请求继续保持关闭，不能因导入工具包获得付费授权。

在工具包卡片点击「参数」修改。轻启将用户覆盖值与签名正文分开保存，更新不会覆盖自定义值。新增参数用包默认值；已删除参数的旧值保留但不传给脚本。参数类型或范围改变导致旧值不适用时，保留旧值并暂停该包，等待用户修正或恢复默认。参数弹窗可全部恢复默认。

参数版每包包含 **2 个 JS 脚本、4 份 JSON 配置**以及许可文本；脚本中共享 Kit 已打包。成分数字统计实际签名载荷文件，不把宿主原生代码计入工具包。

## 仓库结构与维护

- `index.json`：schema 2 多版本索引；同一 `id` 的 `releases` 记录版本、相对地址、完整文件 SHA-256 和兼容要求。
- `packs/<id>/<version>.json`：不可覆盖的签名版本文件；新发布须递增版本，保留既有正文。
- 每份正文的 `manifest.json`、规则、策略、脚本及可选 `config.json` 都在签名范围内。清单不能放宽已签正文的限制；导入仍需用户确认发布者和能力。
- 每个合集最多 32 个工具，每工具最多 32 个版本，总共最多 128 个版本。需要扩展时拆成新的合集入口。
- 顶层原工具仓入口继续独立维护；此目录是复合工具的独立入口。

```sh

```
