2026-11-13：开屏及四份安装／主题包在原 V1 路径更新参数能力，保留本入口既有的目标到达、输入选择和返回接续优化。开屏新增连续未点击自动暂停策略，最低 129527；参数来源标记及逐项、整包恢复默认需轻启 129529。完整参数见[参数清单](../PARAMETERS.md)，同版本重导说明见[原合集说明](../README.md)。

## 2026-11-13 绿泡泡辅助

新增绿泡泡辅助 V1，执行内容对应已验证的本地 V4，要求轻启 129531 和 API26。先点击最上方内联入口，由微信顺序转写未读语音，再长按补做已读但未转写的消息。仅使用原生控件，无截图或OCR；原图按每次打开选图页自动勾选一次，同次手动取消后保持取消。语音范围与原图开关分别可配置。结果等待统一由包内脚本安排，完成或离开微信后停止读取。

本轮Pura70Pro两条已读语音补漏9.55秒，上轮12.93秒；不同消息的单轮对比，不代表稳定平均值。已装本地V3/V4时，按现有版本保护规则移除该包再导入综合仓V1，重导后核对启用状态和语音范围。其余14项及历史订阅保持原内容。

## 2026-11-13 绿泡泡敏捷接续更新

覆盖同一路径 V1，执行内容对应本地 V5，最低轻启 129535、API26；由引擎能力声明选择兼容性，不限制微信应用版本。单次长按时长为包内600ms声明，不再依赖原生批处理；菜单选择后的结果接续由包内脚本安排。主机修复规则重建丢失最低版本、慢原生证明返回后被误判过期，以及转写展开滚动引发的重复接续。真实用户点击仍取消旧目标。

Pura70Pro两条已读语音共4次操作、2次整树读取，8.677秒；上轮9.549秒、4次整树读取。样本为同两条语音取消显示后重测，微信可能保留转写缓存，仅是单轮对比。逐条确认实际转写，重新进入没有重复操作。原图与语音范围沿用原设置，其余14包及历史订阅内容不变。升级后用更新按钮重新取V1；本地V5用户需按原有版本规则移除本地包再导入V1。
