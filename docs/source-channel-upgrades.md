# 旧工具源兼容升级

旧版轻启继续读取原 index.json；原索引、包地址及内容保持不变。

轻启 130004 起，在用户主动刷新、导入或更新旧 schema 1 工具源时，会尝试读取同目录的 index.channels.json。根据当前轻启版本选择作者声明的兼容目录；目录只能指向同一传输源，保留 GitHub 镜像／代理前缀。没有此文件的第三方源继续使用原目录。

当前声明：130004 及以上使用 collections/composite/v1/index.json。新目录仍按 Host API、系统 API 和包声明选择兼容版本，实际安装继续校验签名、摘要、原发布者绑定及用户授权。目录迁移不授予脚本执行权限。

旧索引禁用状态不会被绕过。新版目录已声明但读取失败时，不以旧未签名包替代；刷新后重试即可。仅在用户主动操作时发现，没有新增后台轮询。

历史上卸载的同应用工具包可能保留任务归属。新版会读取同源已签名关联包，只作为独立入口的校验证据，不安装、授权、启用或执行关联包。之后的卸载会保留本机验证过的入口信息，支持离线逐个重装；真实任务重叠、发布者变更或缺少原授权仍拒绝。

新机制没有修改任何工具包的业务脚本或默认参数。
