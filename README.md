- `index.json`：清单，列出包标识、版本与各自的地址（相对地址，镜像会一起解析）。
- `packs/<id>/<version>.json`：每个版本的包正文；正常更新保留已发布版本，清单明确选择当前分发的版本。
- `tools/packs.cjs`：本仓库独立的清单校验与版本导入脚本，无需进入轻启本体工程。
